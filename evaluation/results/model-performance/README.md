## Formulas

```text

total_energy_J = attention_energy_J + ffn_energy_J
total_FLOPs = attention_FLOPs + ffn_FLOPs
throughput_GFLOPS = total_FLOPs / (total_latency_ms * 1e6)
energy_efficiency_GFLOPS_per_J = total_FLOPs / (total_energy_J * 1e9)
```
